# LibHand 0.9 hand model

Marin Šarić, *LibHand: A Library for Hand Articulation*, 2011. The hand model and its skin texture are licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). [Project and model credits](https://www.libhand.org/).

The repository’s `src/openarm_sim/scripts/fetch_libhand_asset.py` converted the skinned OGRE model to a spread-hand Wavefront mesh. `hand.obj.gz` stores that mesh losslessly. The simulation rotates, scales and animates it, then adds a generated cloth sleeve. The original archive checksum is in `source.json`. These credits also apply to the experiment videos and stills.
