# Model Notes

Phase 1 does not run formal SAM 3, RoboPoint, Qwen, or SmolVLM inference.

Planned integrations must record:

- repository URL
- git commit hash
- model revision
- license
- download date
- container digest
- execution hardware

If weights are gated, unavailable, or require login, the service must return a clear blocking reason and formal tests must not be marked passed.
